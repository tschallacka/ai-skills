# Rust artifact manifest

CI publishes the target-specific Rust command bundle together with two
verification files: `RUST-ARTIFACTS.tsv` and `SHA256SUMS`. The bundle contains
one directory per house target and the TSV records one row per file:

```text
target<TAB>file<TAB>sha256
```

`file` is relative to the target directory in the bundle. Verify the complete
download from the bundle root with:

```bash
sha256sum -c SHA256SUMS
```

The hashes are generated by CI from the files it built, after the native
target matrix has executed them. A hash proves the downloaded bytes are the
bytes CI recorded; it does not replace the repository's release provenance or
the platform signature requirements.

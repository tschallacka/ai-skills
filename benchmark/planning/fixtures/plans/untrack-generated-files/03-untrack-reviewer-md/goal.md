# Goal: Untrack planning/REVIEWER.md; generate it wherever it is consumed

## Current state and prior-goal handoffs

§ 2.1
planning/REVIEWER.md is generated by planning/scripts/generate-reviewer.sh from planning/SKILL.md and pinned to its SHA-256; the projection test compares the committed file. role-context.sh reads it for the chris scope; plan-context-lib.sh lists it with a hash behind an existing -f guard; the capsule copies it only if present; installer/build-release.sh hard-errors if it is listed and missing. Prior handoff: goal 02's prepack already generates it when missing.

## Outcome and definition of done

§ 3.1
planning/REVIEWER.md is gitignored and untracked; planning/tests/test-reviewer-projection.sh builds to a temp file and still asserts the SKILL.md SHA-256 pin and the marker set; role-context.sh refuses with an actionable message naming generate-reviewer.sh when the file is absent; plan-context-lib.sh context source listing omits the entry with a stated reason instead of a broken path; installer/build-release.sh runs generate-reviewer.sh; the capsule builds REVIEWER.md; planning/MAINTAINER.md section 1 row matches. Demonstrable: rm REVIEWER.md; role-context.sh chris fails with the named fix; the projection test passes against a fresh temp build; a release tarball and capsule both carry a generated REVIEWER.md.

## Why this goal is needed

§ 4.1
The SHA pin makes this the most self-contained gate: determinism plus pin equals freshness, so the file can be generated wherever it is consumed without weakening any assertion.

## Scope

Out: any change to SKILL.md or the reviewer profile version, and plan-context paging behaviour beyond the listing line.

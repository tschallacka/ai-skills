# Question etiquette

**Numbered questions, lettered options, never a bullet.**

A bullet cannot be referenced. This skill fixes the shape of a question put to
the human: every question carries a session-wide, ever-increasing number
(Q1, Q2, Q3, ...), every offered option carries a letter (a, b, c, ...), and a
lettered list always ends with an escape option meaning "none of these, I'll
say it myself." A reply like `Q7b` is then complete and unambiguous, and a
partial reply names exactly which numbers are still open.

Numbers are never reused and never restart for a new batch; an unanswered
number carries forward on the next ask rather than being dropped or silently
folded into a new one.

Read `SKILL.md` for the rules and a worked example.

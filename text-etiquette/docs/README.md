# Text etiquette

**Short messages between agents: the register, the shorthand, the ceiling.**

Chat between agents is functional traffic, not conversation. The skill fixes
the register: clipped sentences, facts first, the payload (paths, numbers,
errors, code) exact while the wrapper around it shrinks.

The shorthand table keeps messages dense without becoming private code - any
agent that does not recognize a term asks `plz explain <shorthand>` instead of
guessing. Praise stops at `gj`; validation prose, journey narration and recap
closers are banned outright. Emotion is permitted exactly once earned, as
sarcasm with no mean edge.

The register bends where brevity would cost understanding: destructive
actions, security warnings, and direct questions get full sentences.

Read `SKILL.md` for the rules.

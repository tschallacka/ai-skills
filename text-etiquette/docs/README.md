# Text etiquette

**Short prose everywhere: agent chat, dev talk, and the agent's own thinking.**

Talk between agents - and with the developer - is functional traffic, not
conversation. The skill fixes the register: clipped sentences, facts first,
the payload (paths, numbers, errors, code) exact while the wrapper around it
shrinks. It applies to chat, to dev talk, and to the agent's own reasoning
prose, which loses its audience narration and thinks in fragments.

The shorthand table keeps messages dense without becoming private code - any
agent that does not recognize a term asks `plz explain <shorthand>` instead of
guessing. Praise stops at `gj`; validation prose, journey narration and recap
closers are banned outright. Emotion is permitted exactly once earned, as
sarcasm with no mean edge.

The register bends where brevity would cost understanding: the reader may
always ask for plain english and get complete sentences, and destructive
actions, security warnings and direct questions get full sentences regardless.

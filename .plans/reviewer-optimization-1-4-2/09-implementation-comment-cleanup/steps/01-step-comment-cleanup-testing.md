# Verification

Review the final implementation diff and comment inventory after all code changes are complete. Pass only when:

- comments that narrate the developer journey, duplicate obvious code, or contain stale debugging notes are removed;
- retained comments are concise and each explains non-obvious intent, constraints, invariants, compatibility, security, or trade-offs;
- plan, benchmark, audit, and analysis records remain intact;
- the final diff shows no unintended behavior or source changes; and
- the relevant focused test/validation commands pass after cleanup.

# The split between the planning tests that ship and the ones that do not is
# historical, not a rule: both halves compute the repo root the same way and both
# reach outside the skill directory, so there is no property that sorts them.
# Deciding which of these belong in an install is a maintainer call, and this file
# holds them until it is made.

# file outside skill_files() appears here, so a newly added test must either be
# registered for shipping or added deliberately to this list -- it can no longer
# go unshipped by nobody noticing. Entries may be removed (by registering the file
# in PACKAGE-MANIFEST.txt, PACKAGE-MAP.tsv and skill_files()). Adding one is a
# decision to make, not a formality.
